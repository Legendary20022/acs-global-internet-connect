How to use this demo

  1. Open Provider or Organisation and create an offer code.
  2. Copy the code shown.
  3. Open Receiver, enter the code, and request access.
  4. Return to Provider to approve or reject the demo request.

Demo data is saved only in this browser on this device. It is not shared between different users or phones.

What is still needed for a real service?

  • A secure online backend and user accounts.
  • Authorised networking integration on both the hotspot and receiver sides.
  • Appropriate relay/tunnel infrastructure and carrier-plan permission.
  • A compliant payment provider, if paid access is offered.
  • Security testing and production deployment.
